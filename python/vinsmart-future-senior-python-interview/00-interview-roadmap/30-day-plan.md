# 30-day Plan

## Nhịp mỗi ngày

1. 45 phút active recall; 60–90 phút deep study; 30 phút interview questions.
2. 30 phút scenario/System Design hoặc coding có timer.
3. Ghi `gap → correct model → production example`; review theo spaced repetition 1/3/7 ngày.

## Schedule

- [ ] **Ngày 1–5:** Python memory, GC, data model, typing; mỗi ngày 15 câu hỏi. Output: one-page recall + trả lời thành tiếng + một scenario.
- [ ] **Ngày 6–9:** GIL, threading, multiprocessing, AsyncIO, cancellation và race. Output: one-page recall + trả lời thành tiếng + một scenario.
- [ ] **Ngày 10–13:** FastAPI lifecycle/DI/auth/performance + SQLAlchemy session/N+1. Output: one-page recall + trả lời thành tiếng + một scenario.
- [ ] **Ngày 14–18:** PostgreSQL index/planner/MVCC/transaction/locks/pool; đọc plan thật. Output: one-page recall + trả lời thành tiếng + một scenario.
- [ ] **Ngày 19–21:** Redis + Celery; drill cache down, stampede, duplicate task. Output: one-page recall + trả lời thành tiếng + một scenario.
- [ ] **Ngày 22–25:** Distributed Systems + Architecture + API Design. Output: one-page recall + trả lời thành tiếng + một scenario.
- [ ] **Ngày 26–27:** System Design: AI Chatbot, Warranty, Document, Video. Output: one-page recall + trả lời thành tiếng + một scenario.
- [ ] **Ngày 28:** Docker/Kubernetes/Cloud/Terraform/Security theo P1. Output: one-page recall + trả lời thành tiếng + một scenario.
- [ ] **Ngày 29:** Coding patterns + 6 Behavioral stories. Output: one-page recall + trả lời thành tiếng + một scenario.
- [ ] **Ngày 30:** Full mock 110 phút, review gap và nghỉ sớm. Output: one-page recall + trả lời thành tiếng + một scenario.

## Exit criteria

- P0: giải thích 2 phút không nhìn notes và chịu được ít nhất ba follow-up.
- Scenario: mitigation trước diagnosis sâu; có metric/query, long-term fix và prevention.
- System Design: estimate có đơn vị, API/data model, bottleneck, failure/security/observability.
- Behavioral: mỗi story dưới 3 phút, có con số, decision cá nhân và learning.
